Mode d'emploi Brevo

Chaque bloc s'affiche tel qu'il rendra dans l'email, avec un bouton pour copier son code.

1. Créer un template

  1. Brevo > Campagnes > Modèles > Nouveau modèle, éditeur Code HTML.
  2. Collez d'abord le squelette de base ci-dessous (en-tête, polices, fond gris, conteneur centré).

2. Squelette de base

<!DOCTYPE html>
<html lang="fr"><head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link href="https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700;800&family=Fraunces:ital,opsz,wght@1,9..144,400;1,9..144,500;1,9..144,600&display=swap" rel="stylesheet">
  <style>
    body{margin:0;padding:0;background:#F5F3F3;}
    @media only screen and (max-width:600px){
      .duo-col{display:block!important;width:100%!important;padding:0 0 24px 0!important;text-align:center;}
    }
  </style>
</head>
<body style="margin:0;padding:0;background:#F5F3F3;">
  <table role="presentation" width="100%" cellpadding="0" cellspacing="0" border="0" style="background:#F5F3F3;">
    <tr><td align="center" style="padding:20px 0;">
      <!-- COLLEZ VOS BLOCS ICI -->
    </td></tr>
  </table>
</body></html>

3. Ajouter des blocs

  1. Cliquez sur Copier le code au-dessus du bloc voulu.
  2. Collez entre les balises <!-- COLLEZ VOS BLOCS ICI -->, dans l'ordre souhaité.
  3. Commencez par un header, finissez par un footer.

4. Personnaliser

  • Remplacez chaque URL_PHOTO / URL_IMAGE / URL_HERO par vos vraies images hébergées.
  • Remplacez chaque URL_ICONE par un PNG d'icône hébergé.
  • Remplacez URL_HEBERGEMENT, URL_CARTE_CADEAU, etc. par vos liens, et {{ unsubscribe }} par la balise de désinscription Brevo.

5. Héberger les images sur Vercel

Déposez logos, icônes, photos et heros dans votre projet Vercel et utilisez les URLs stables obtenues.

6. Créer plusieurs templates

Composez un modèle, puis dupliquez-le dans Brevo et adaptez les blocs pour chaque newsletter.

7. Quelle méthode choisir

  • Automations et emails figés (bienvenue, anniversaire, enquête) : HTML collé tel quel, parfait, risque quasi nul.
  • Newsletters hebdomadaires : reconstruisez les blocs clés en blocs réutilisables Brevo, pour une édition en visuel sans toucher au code.
  • Dans les deux cas, ce fichier reste la référence et la source du code.

8. Créer un bloc réutilisable Brevo

  1. Ouvrez un email en éditeur Drag & Drop.
  2. Glissez le composant adapté (Image, Image + Texte, Bouton), reproduisez la mise en page avec ce catalogue comme référence et les couleurs exactes du design system.
  3. Survolez le bloc, cliquez sur Enregistrer le bloc, nommez-le (ex. ABCD - Hébergement).
  4. Il rejoint Mes blocs, éditable en visuel.

Priorité : Hero, Hébergement, Réassurance avis, Carte cadeau.

Titres et rubans stylés. Les heros et rubans typologie posés sur photo se produisent comme images dans Design, titre incrusté. En email, un texte sur image se décale sur Outlook.
Toujours tester. Vérifiez le rendu Outlook et mobile. Les coins arrondis apparaissent carrés sur Outlook desktop, sans gravité. Outfit et Fraunces basculent en Arial et Georgia sur Outlook.
